Comment jouer

Règles

  1. Un point devient jaune parmi tous les autres.
  2. Tous les points se mettent à bouger sur le cercle.
  3. Après quelques secondes, le jaune redevient blanc — il se fond dans la masse.
  4. Les points continuent de bouger. Reste concentré, garde-le à l'œil.
  5. Appuie sur STOP quand tu es prêt : tout se fige.
  6. Clique sur le point que tu penses être le bon.
  7. Le vrai point s'illumine en jaune : victoire ou défaite.

Mode multijoueur — élimination

  1. L'hôte choisit le nombre de points de départ, la vitesse de départ et le temps à partir duquel on peut appuyer sur STOP, puis invite les autres joueurs.
  2. Tous les joueurs jouent la même manche en même temps.
  3. Tout joueur qui désigne le mauvais point est éliminé. La partie continue pour les autres.
  4. À chaque nouvelle manche, le nombre de points et la vitesse augmentent progressivement.
  5. La partie se termine lorsqu'il ne reste qu'un seul joueur : le vainqueur.
